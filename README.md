# Smart Room Monitor - IoT Application Project

Sistem monitoring ruangan berbasis ESP32: suhu, kelembaban, kualitas udara, dan deteksi gerakan. Data dikirim ke Firebase dan ditampilkan di aplikasi.

## Tim
Lihat [PROFIL_TIM.md](PROFIL_TIM.md)

## Struktur Rencana
- `firmware/` - kode ESP32 (Arduino)
- `app/` - kode aplikasi mobile/web
- `docs/` - proposal, wiring, presentasi

## Quick Start
1. Upload `firmware/` ke ESP32
2. Setup Firebase Realtime Database
3. Jalankan aplikasi dan hubungkan ke Firebase
